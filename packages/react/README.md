# @rebyte/agent-react

Headless React state and transports for Rebyte Agents.

```sh
pnpm add \
  https://github.com/ReByteAI/rebyte-agent-sdk/releases/latest/download/rebyte-agent-sdk.tgz \
  https://github.com/ReByteAI/rebyte-agent-sdk/releases/latest/download/rebyte-agent-react.tgz
```

Use `useRebyteChat` with `createFetchTransport` in a browser. It produces messages, streamed response state, errors, server-side interruption, and stable Conversation continuity without rendering UI.

See the [repository README](../../README.md#headless-react) for usage.
