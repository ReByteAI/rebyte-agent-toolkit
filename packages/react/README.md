# @rebyte/agent-react

Headless React state and transports for Rebyte Agents.

```sh
pnpm add @rebyte/agent-react @rebyte/agent-sdk
```

Use `useRebyteChat` with `createFetchTransport` in a browser. It produces messages, streamed response state, errors, cancellation, and Response ID continuity without rendering UI.

See the [repository README](../../README.md#headless-react) for usage.
