# @rebyte/agent-ui

Optional App Kit-style React UI for Rebyte Agents.

```sh
pnpm add \
  https://github.com/ReByteAI/rebyte-agent-sdk/releases/latest/download/rebyte-agent-sdk.tgz \
  https://github.com/ReByteAI/rebyte-agent-sdk/releases/latest/download/rebyte-agent-react.tgz \
  https://github.com/ReByteAI/rebyte-agent-sdk/releases/latest/download/rebyte-agent-ui.tgz
```

Import `@rebyte/agent-ui/styles.css`, then render `AgentChat` with an `AgentTransport`. Use `AgentChatView` when your application owns the headless state.

See the [repository README](../../README.md#optional-ui) for usage.
