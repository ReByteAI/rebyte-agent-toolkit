# @rebyte/agent-sdk

Framework-free TypeScript client for Rebyte Agents, durable Conversations, and `/v1/responses`.

```sh
pnpm add https://github.com/ReByteAI/rebyte-agent-sdk/releases/download/v0.1.0/rebyte-agent-sdk-0.1.0.tgz
```

See the [repository README](../../README.md#core-sdk) for usage. Organization API keys are intended for trusted server runtimes; the client refuses browser construction unless `dangerouslyAllowBrowser` is explicitly set.
