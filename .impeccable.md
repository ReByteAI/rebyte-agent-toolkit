## Design Context

### Users

Enterprise Agent developers evaluating or integrating the Rebyte browser
packages, plus operators using the hosted App Kit to verify a managed Agent.
Their job is to send text and files, see streaming output and tool execution,
and understand the trust boundary without exposing an organization API key.

### Brand Personality

Confident, precise, and restrained. Rebyte should feel like serious execution
infrastructure presented with editorial clarity: calm while idle, visibly alive
while an Agent is working, and direct when something fails.

### Aesthetic Direction

Preserve the existing warm-paper and deep-navy interface, serif display type,
compact technical inspector, and paired light/dark themes. New controls should
feel native to the composer rather than added as a generic card or modal. Avoid
neon AI styling, ornamental gradients, excessive rounding, and hidden critical
actions. The interface must adapt fully to mobile.

### Design Principles

1. Make every supported capability visible and directly testable in the UI.
2. Keep the default composer quiet; reveal file detail and progress only after selection.
3. Show truthful state for upload, streaming, completion, cancellation, and failure.
4. Keep organization credentials behind the application-server boundary.
5. Preserve touch targets, keyboard operation, reduced motion, and readable contrast.
